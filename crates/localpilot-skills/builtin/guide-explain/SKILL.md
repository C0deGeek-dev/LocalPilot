## Procedure
- Answer the question that was asked, from the code that is relevant to it and the project's own conventions.
- Read before you answer: find the definition, its callers and the data it handles. Cite files and lines.
- Keep what you observed apart from what you infer. Say which parts you did not read.
- Do not edit files, and do not build or launch the application, to answer an explanation. Run a check only when the user asked for one or when a single check settles the question.
- End with the answer, not with a list of changes you could make.
