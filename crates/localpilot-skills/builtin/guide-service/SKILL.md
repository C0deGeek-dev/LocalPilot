## Services
- Behaviour is the response to a request and the state it leaves: status, body, headers and what is stored.
- Run an isolated local instance on a free port, wait until it is actually ready, and stop it afterwards.
- Exercise the valid request and the invalid ones the change is about, and check the state after each.
- A successful build or a port that accepts connections does not show endpoint behaviour.
- Do not invent credentials, and do not point at shared or production services or databases.
