## Procedure
- State the reported input, the expected result and the actual result. If one is missing, say so.
- Locate the code path that produces the actual result. Read it; do not guess from names.
- Reproduce the problem when that is permitted and practical, with the smallest input that shows it.
- Separate the confirmed cause from hypotheses. A hypothesis becomes a cause only when an observation supports it.
- Leave unrelated code and unrelated failures alone.
- If you cannot reproduce it, report the smallest next observation that would decide it.
- When the user asked for a fix, continue with the change and then show that the same input now gives the expected result.
