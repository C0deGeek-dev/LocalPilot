## Godot 4
- Confirm the engine version in `project.godot` and which scene the change is about before choosing how to run anything.
- Read the scene, the scripts attached to it and the input map. A generated `.csproj` describes the C# build, not how the game runs.
- Headless import or script checks show that the project loads, not that a scene behaves or looks right.
- For gameplay changes, run the intended scene and reproduce the input and the state change when a controlled way to do so exists.
- Do not claim that lighting, framing or collisions were verified from a successful import.
