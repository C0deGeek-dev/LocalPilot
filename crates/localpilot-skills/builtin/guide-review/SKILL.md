## Procedure
- Read the material you were asked to review, and enough of its surroundings to judge it.
- Report problems that matter: wrong results, regressions, missing error handling, unsafe input handling, broken contracts. Give the file and line, the failure it causes, and how sure you are.
- Do not repair what you find, do not reformat, and do not widen the review to unrelated code unless asked.
- A review of unchanged code does not need the application launched. Run a check only when it decides a finding.
- Say what you did not review.
